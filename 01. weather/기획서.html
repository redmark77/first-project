01

프로젝트 개요

도시 이름을 검색하거나 현재 위치를 이용해 실시간 날씨와 주간 예보를 보여주는 한국어 웹앱입니다. 회원가입이나 API 키 없이 Open-Meteo(예보)와 Nominatim(지명 검색, OpenStreetMap)만으로 동작하도록 만들어졌습니다.

같은 기능을 가진 두 가지 구현체가 나란히 존재합니다 — 처음 만든 순수 HTML/CSS/JS 버전과, 이후 다시 작성한 Vite + TypeScript 버전(weather-vite/)입니다.

03

핵심 기능

🔍 도시 검색 자동완성
2자 이상 입력 시 600ms 디바운스 후 Nominatim으로 후보 최대 5개 조회, 지역명과 함께 드롭다운 표시.
📍 현재 위치 조회
브라우저 Geolocation API로 좌표를 얻어 바로 날씨를 표시. 미지원/거부 시 에러 메시지 표시.
🌡️ 실시간 날씨
현재 기온, 체감 온도, 습도, 풍속과 날씨 상태(코드→설명/아이콘 매핑)를 카드로 표시.
📅 주간 예보
오늘 포함 향후 예보의 요일별 최고/최저 기온과 날씨 아이콘을 목록으로 표시.
⌨️ 검색 UX
Enter로 첫 결과 바로 선택, 바깥 클릭 시 드롭다운 닫힘, 검색 실패/네트워크 오류 안내 메시지 처리.
🈚 API 키 불필요
Open-Meteo·Nominatim 모두 무료/무인증 공개 API라 백엔드나 키 관리가 필요 없음.

07

테스트·검증 현황

정식 자동화 테스트 코드(*.spec.ts 등)는 저장소에 없습니다. test-results/.last-run.json과 4장의 스크린샷(naver-home.png, naver-search-choiseungho.png, google-search-vibe-coding.png, weather-vite-seoul.png)은 Playwright/Chrome 브라우저 자동화로 서울 날씨 조회 등을 수동 확인한 결과물로 보입니다.

참고 — .last-run.json은 status "failed"를 기록하고 있지만 failedTests 목록은 비어 있어, 실제 회귀 테스트 스위트가 아니라 임시 실행 흔적에 가깝습니다.
