# 쇼핑몰 프로젝트 대화 요약 (Prompt / AI 응답)

---

### 1
**Prompt (사용자):**
> 내가 쇼핑몰을 만들려고 한다. 어떤 기능들이 필요할까?

**AI 응답:**
쇼핑몰 종류(단일 판매자 vs 마켓플레이스), 기술 스택 선호, 결제 연동 필요 여부를 확인하기 위해 질문을 던짐. 사용자 답변을 받아 아래를 확정:
- 단일 판매자 쇼핑몰
- Next.js + Node/DB 스택
- 결제 연동은 후순위 (지금은 상품/장바구니/주문 흐름까지만)

이를 바탕으로 전체 기능 목록, 기술 스택, MVP 범위, 프로젝트 구조를 담은 계획을 작성함 (Plan Mode).

---

### 2
**Prompt (사용자):**
계획 승인 요청(ExitPlanMode)을 **거절**함 — 별도 텍스트 메시지 없이 승인을 보류.

**AI 응답:**
승인 거절을 확인하고 다음 사용자 메시지를 기다림 (계획 파일은 그대로 유지).

---

### 3
**Prompt (사용자):**
> 그러면 가장 간단한 형태로 만들려면 어떻게 해야 할까?

**AI 응답:**
가장 단순한 형태로 가려면 두 가지를 줄이면 된다고 제안:
- DB를 **SQLite**(파일 기반)로 변경 → 별도 서버 설치 없이 바로 실행
- **관리자 화면과 회원 인증을 없애고**, 상품은 시드 스크립트/JSON으로 미리 등록한 뒤 고객 플로우(목록 → 상세 → 장바구니 → 주문완료)만 먼저 구현

트레이드오프(나중에 회원/관리자 기능 필요 시 다시 추가해야 함)를 설명하고, 이 방향으로 계획을 줄여도 될지, 아니면 회원가입/로그인은 남길지 확인 질문을 던짐.

---

### 4
**Prompt (사용자):**
`/export`, `/compact`, `/memory` 명령 실행 후:
> 요약된 내용을 파일로 저장해줘

**AI 응답:**
Plan Mode 중이라 새 파일 생성이 제한된다는 점을 안내하고, 저장 방식(Plan Mode 종료 후 저장 / 기존 export 파일 사용)을 확인하는 질문을 던짐.
→ 사용자가 **"Plan Mode 종료 후 저장"** 선택.

이어서 계획 단순화 방향(회원가입/로그인 포함 여부)을 재확인하려는 질문을 던졌으나, 사용자가 이를 **거절**.

---

### 5
**Prompt (사용자):**
> 요약된 내용을 현재 폴더에 파일을 만들어 저장해줘

**AI 응답:**
추가 질문 없이 바로 **Plan Mode를 종료**(ExitPlanMode)하고, 그동안의 기획 내용(배경/기능 목록/기술 스택/MVP 범위/프로젝트 구조/검증 방법 + 단순화 논의 현황)을 정리하여
`C:\vibeCoding\10.Test\02. shopping mall\project-summary.md` 파일로 저장함.

---

### 6
**Prompt (사용자):**
> 내가 작성한 prompt와 AI 응답 세트로 작성해줘

**AI 응답:**
`project-summary.md`를 주제별 요약 형식에서 **대화 순서대로 Prompt / AI 응답 쌍**으로 재구성하여 저장 (현재 문서).
